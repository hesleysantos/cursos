# Comparativos, superlativos, as...as, too/enough; cidades e viagens

Comparar é uma das coisas mais úteis que se faz em qualquer língua: qual cidade é maior, qual voo é mais barato, qual hotel é o melhor. Nesta lição você aprende os **comparativos** (-er / more), os **superlativos** (-est / most), a estrutura **as...as**, as palavras **too** e **enough**, e pratica com o vocabulário de **cidades, viagens e meios de transporte**.

## Comparativos: "mais ... do que"

A forma depende do **tamanho** do adjetivo:

| Tipo de adjetivo | Regra | Exemplos |
|---|---|---|
| curto (1 sílaba) | + **er** | {{en:cheap}} → {{en:cheaper}}, {{en:fast}} → {{en:faster}}, {{en:old}} → {{en:older}} |
| curto terminado em -e | + **r** | {{en:large}} → {{en:larger}}, {{en:nice}} → {{en:nicer}} |
| consoante-vogal-consoante | dobra + er | {{en:big}} → {{en:bigger}}, {{en:hot}} → {{en:hotter}} |
| 2 sílabas em -y | y → **ier** | {{en:easy}} → {{en:easier}}, {{en:busy}} → {{en:busier}}, {{en:happy}} → {{en:happier}} |
| longo (2+ sílabas) | **more** + adjetivo | {{en:more expensive}}, {{en:more important}}, {{en:more comfortable}} |
| irregular | | {{en:good}} → {{en:better}}, {{en:bad}} → {{en:worse}}, {{en:far}} → {{en:farther}} |

O "do que" é **than**:

- {{en:São Paulo is bigger than Aracaju.}} — São Paulo é maior que Aracaju.
- {{en:The bus is cheaper than the taxi.}} — O ônibus é mais barato que o táxi.
- {{en:This hotel is more expensive than that one.}} — Este hotel é mais caro que aquele.
- {{en:English is easier than German.}} — Inglês é mais fácil que alemão.
- {{en:My new job is better than my old job.}} — Meu novo emprego é melhor que o antigo.
- {{en:Traffic today is worse than yesterday.}} — O trânsito hoje está pior que ontem.

> **Atenção:** erros clássicos: "more big" (certo: {{en:bigger}}), "more easy" (certo: {{en:easier}}), "more better" (certo: {{en:better}}) e usar "that" em vez de **than**: "bigger that". Fixe: comparativo + **than**.

Para dizer "muito mais", use **much**: {{en:much cheaper}}, {{en:much more expensive}}. Para "um pouco mais": {{en:a little bigger}}.

## Superlativos: "o mais ..."

Mesma lógica, com **-est** ou **most**, e sempre com **the** antes:

| Tipo | Regra | Exemplos |
|---|---|---|
| curto | the + **est** | {{en:the cheapest}}, {{en:the fastest}}, {{en:the biggest}} |
| 2 sílabas em -y | the + **iest** | {{en:the easiest}}, {{en:the busiest}} |
| longo | the **most** + adjetivo | {{en:the most expensive}}, {{en:the most important}} |
| irregular | | {{en:the best}}, {{en:the worst}}, {{en:the farthest}} |

- {{en:São Paulo is the biggest city in Brazil.}} — São Paulo é a maior cidade do Brasil.
- {{en:This is the cheapest flight.}} — Este é o voo mais barato.
- {{en:It's the most beautiful beach in the world.}} — É a praia mais bonita do mundo.
- {{en:Monday is the busiest day of the week.}} — Segunda é o dia mais cheio da semana.
- {{en:This is the best coffee in town.}} — Este é o melhor café da cidade.
- {{en:It was the worst trip of my life.}} — Foi a pior viagem da minha vida.

Depois do superlativo, "do/da" é **in** para lugares ({{en:in Brazil}}, {{en:in the world}}, {{en:in the office}}) e **of** para períodos e grupos ({{en:of the year}}, {{en:of my life}}, {{en:of all}}).

## As ... as: "tão ... quanto"

Para dizer que duas coisas são **iguais**, use **as + adjetivo + as**. Na negativa, "não tão ... quanto":

- {{en:Aracaju is as hot as Recife.}} — Aracaju é tão quente quanto Recife.
- {{en:The train is as fast as the car.}} — O trem é tão rápido quanto o carro.
- {{en:This hotel isn't as expensive as the Hilton.}} — Este hotel não é tão caro quanto o Hilton.
- {{en:My English isn't as good as yours.}} — Meu inglês não é tão bom quanto o seu.

Repare que o adjetivo fica na forma **normal** (sem -er). "As bigger as" está errado.

## Too e enough

**Too** = "demais" (mais do que o aceitável; tem sentido negativo). Vem **antes** do adjetivo.
**Enough** = "suficiente". Vem **depois** do adjetivo e **antes** do substantivo.

| Estrutura | Exemplo |
|---|---|
| too + adjetivo | {{en:The ticket is too expensive.}} (caro demais) |
| adjetivo + enough | {{en:The room isn't big enough.}} (não é grande o suficiente) |
| enough + substantivo | {{en:We don't have enough time.}} (não temos tempo suficiente) |
| too much / too many + substantivo | {{en:There's too much traffic.}} / {{en:There are too many people.}} |

- {{en:It's too far to walk. Let's take a taxi.}} — É longe demais para ir a pé. Vamos de táxi.
- {{en:I'm too tired to drive.}} — Estou cansado demais para dirigir.
- {{en:Is the water warm enough?}} — A água está quente o suficiente?
- {{en:I don't have enough money for a flight.}} — Não tenho dinheiro suficiente para um voo.

> **Dica:** não confunda **too** (demais) com **very** (muito). {{en:It's very expensive}} é só uma informação. {{en:It's too expensive}} significa "caro demais, não vou comprar".

|---|---|
| {{en:trip}} / {{en:journey}} / {{en:travel}} | viagem / trajeto / viajar (verbo) |
| {{en:by car}} / {{en:by bus}} / {{en:by train}} / {{en:by plane}} | de carro / ônibus / trem / avião |
| {{en:on foot}} | a pé |
| {{en:subway}} (EUA) / {{en:underground}} (Reino Unido) | metrô |
| {{en:taxi}} / {{en:ride-sharing app}} | táxi / aplicativo de carona |
| {{en:ticket}} / {{en:one-way}} / {{en:round trip}} | passagem / só ida / ida e volta |

| {{en:timetable}} / {{en:schedule}} | horário (tabela) |
| {{en:book}} (verbo) | reservar |
| {{en:luggage}} | bagagem |

Para dizer como vai: **by** + meio de transporte, sem artigo ({{en:by bus}}, não "by the bus"); a pé é {{en:on foot}}.

- {{en:How do you get to work? By car. It takes 20 minutes.}} — Como você vai ao trabalho? De carro. Leva 20 minutos.
- {{en:The train is faster than the bus, but the bus is cheaper.}}
- {{en:A round-trip ticket to Recife, please.}} — Uma passagem de ida e volta para Recife.
- {{en:Which platform does the train leave from?}} — De qual plataforma sai o trem?
- {{en:I booked the cheapest flight I could find.}} — Reservei o voo mais barato que achei.

> **Atenção:** {{en:travel}} é o **verbo** (ou a ideia geral); "uma viagem" é {{en:a trip}}. "I made a travel" está errado: {{en:I went on a trip}} / {{en:I took a trip}}. E "take" é o verbo para transporte: {{en:take the bus}}, {{en:take a taxi}}.

## Pronúncia

- Em {{en:bigger}}, {{en:cheaper}}, {{en:faster}}, o "-er" final é um schwa fraco, nunca "ér" forte.
- {{en:than}} na frase é fraco e rápido ("dân"), th sonoro. Não confunda com {{en:then}} (então).
- {{en:worse}} rima com "nurse"; {{en:worst}} tem o "t" final.
- {{en:enough}} termina em som de "f": "i-NÂF".

## Erros comuns

| Errado | Certo |
|---|---|
| more big / more easy | {{en:bigger}} / {{en:easier}} |
| more better | {{en:better}} |
| bigger that Aracaju | {{en:bigger than Aracaju}} |
| the most cheap | {{en:the cheapest}} |
| as bigger as | {{en:as big as}} |
| enough big / by the bus | {{en:big enough}} / {{en:by bus}} |

## Diálogo: escolhendo como viajar

- {{en:I need to go to Salvador next week. What's the best way to get there?}}
- {{en:The plane is the fastest, of course. It's only 50 minutes.}}
- {{en:But it's too expensive this month. How about the bus?}}
- {{en:The bus is much cheaper, but it's slower. It takes about six hours.}}
- {{en:Is it as comfortable as the plane?}}
- {{en:Not really, but the night bus is good enough. You can sleep.}}
- {{en:OK, I'll take the bus. Is the bus station far from here?}}
- {{en:No, it's closer than the airport. You can go on foot.}}

## Na prática

Comparar é o trabalho do contador quando ajuda um cliente a decidir: qual regime tributário é mais barato, qual banco cobra menos, qual mês foi o melhor. Em uma reunião, isso sai com comparativos e superlativos: {{en:This plan is cheaper than the other one, but the second is the safest option.}} Too e enough entram quando algo não serve: {{en:The deadline is too short, and we don't have enough documents.}} Nas viagens de trabalho, o mesmo vocabulário escolhe hotel e transporte: {{en:The train is as fast as the plane and much cheaper.}}

## Resumo

- Comparativo: adjetivo curto **+er** ({{en:bigger}}), longo **more +** ({{en:more expensive}}), sempre com **than**.
- Superlativo: **the +est** ({{en:the biggest}}) / **the most** ({{en:the most expensive}}); depois, **in** para lugar, **of** para período.
- Irregulares: {{en:better}} / {{en:the best}}, {{en:worse}} / {{en:the worst}}.
- Igualdade: **as ... as** com adjetivo normal; negativa {{en:not as ... as}}.
- **too** (demais) antes do adjetivo; **enough** (suficiente) depois do adjetivo e antes do substantivo.
- Transporte: **by** + meio ({{en:by bus}}), {{en:on foot}}, {{en:take a taxi}}; viagem é {{en:a trip}}.
